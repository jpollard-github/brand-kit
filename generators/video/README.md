# Video Generator

Use this generator for stream or video thumbnail artwork.

## Command

```bash
npm run brand:stream-thumbnail
```

## Outputs

- `generators/outputs/video/arcadeghosts-stream-thumbnail.svg`
- `generators/outputs/video/arcadeghosts-stream-thumbnail.png`

## What To Upload

- Default upload file:
  `arcadeghosts-stream-thumbnail.png`
- Editable source:
  `arcadeghosts-stream-thumbnail.svg`
