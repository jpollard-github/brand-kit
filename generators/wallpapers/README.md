# Wallpaper Generator

Use this generator for desktop and mobile wallpaper exports.

## Command

```bash
npm run brand:wallpapers
```

## Outputs

- `generators/outputs/wallpapers/arcadeghosts-wallpaper-desktop.svg`
- `generators/outputs/wallpapers/arcadeghosts-wallpaper-desktop.png`
- `generators/outputs/wallpapers/arcadeghosts-wallpaper-mobile.svg`
- `generators/outputs/wallpapers/arcadeghosts-wallpaper-mobile.png`

## What To Use

- Desktop wallpaper:
  `arcadeghosts-wallpaper-desktop.png`
- Mobile wallpaper:
  `arcadeghosts-wallpaper-mobile.png`
- Editable sources:
  matching SVG files
