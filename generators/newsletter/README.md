# Newsletter Generator

Use this generator for wide newsletter or campaign header art.

## Command

```bash
npm run brand:newsletter
```

## Outputs

- `generators/outputs/newsletter/arcadeghosts-newsletter-header.svg`
- `generators/outputs/newsletter/arcadeghosts-newsletter-header.png`

## What To Upload

- Default upload / embed file:
  `arcadeghosts-newsletter-header.png`
- Editable source:
  `arcadeghosts-newsletter-header.svg`
