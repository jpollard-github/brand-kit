# Sticker Generator

Use this generator family for single sticker art and proof-style sticker sheets.

## Commands

```bash
npm run brand:stickers
npm run brand:sticker-sheet
```

## Outputs

- `generators/outputs/stickers/arcadeghosts-sticker-set.svg`
- `generators/outputs/stickers/arcadeghosts-sticker-sheet.svg`
- `generators/outputs/stickers/arcadeghosts-sticker-sheet.png`

## What To Upload

- Actual vendor upload:
  `arcadeghosts-sticker-set.svg`
- Proof / planning artifact:
  `arcadeghosts-sticker-sheet.png`

If the vendor does not handle SVG cleanly, convert the sticker art to a high-resolution PNG first.
