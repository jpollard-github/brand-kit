# Conference Badge Generator

Use this generator for portrait badge previews or event handoff art.

## Command

```bash
npm run brand:conference-badge
```

## Outputs

- `generators/outputs/badges/arcadeghosts-conference-badge.svg`
- `generators/outputs/badges/arcadeghosts-conference-badge.png`

## What To Upload

- Default print / preview file:
  `arcadeghosts-conference-badge.png`
- Editable source:
  `arcadeghosts-conference-badge.svg`
