# Document Generator

Use this generator for branded stationery-style outputs such as a printable letterhead shell and a client-facing invoice layout.

## Command

```bash
npm run brand:documents
```

## Outputs

- `generators/outputs/documents/arcadeghosts-letterhead.svg`
- `generators/outputs/documents/arcadeghosts-letterhead.png`
- `generators/outputs/documents/arcadeghosts-invoice.svg`
- `generators/outputs/documents/arcadeghosts-invoice.png`

## What To Use

- PNGs for review, proofing, or quick uploads:
  `arcadeghosts-letterhead.png`, `arcadeghosts-invoice.png`
- SVGs as editable source shells:
  `arcadeghosts-letterhead.svg`, `arcadeghosts-invoice.svg`

These are intentionally branded document shells, not a full accounting or proposal system.
