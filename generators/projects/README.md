# Project Cover Generator

Use this generator for repo, project, or portfolio cover art.

## Command

```bash
npm run brand:project-cover
```

## Outputs

- `generators/outputs/projects/arcadeghosts-project-cover.svg`
- `generators/outputs/projects/arcadeghosts-project-cover.png`

## What To Upload

- Default upload file:
  `arcadeghosts-project-cover.png`
- Editable source:
  `arcadeghosts-project-cover.svg`
