# Poster Generator

Use this generator for mini-flyer or poster-style assets.

## Command

```bash
npm run brand:mini-flyer
```

## Outputs

- `generators/outputs/posters/arcadeghosts-mini-flyer.svg`
- `generators/outputs/posters/arcadeghosts-mini-flyer.png`

## What To Upload

- Default print / share file:
  `arcadeghosts-mini-flyer.png`
- Editable source:
  `arcadeghosts-mini-flyer.svg`
