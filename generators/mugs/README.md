# Mug Generator

Use this generator for mug-side and wrap artwork.

## Command

```bash
npm run brand:mugs
```

## Outputs

- `generators/outputs/mugs/arcadeghosts-mug-side-a.svg`
- `generators/outputs/mugs/arcadeghosts-mug-side-b.svg`
- `generators/outputs/mugs/arcadeghosts-mug-wrap.svg`

## What To Upload

- Default vendor upload:
  `arcadeghosts-mug-wrap.svg`

If your vendor needs a flattened bitmap, export the wrap as a high-resolution PNG sized to the vendor template.
