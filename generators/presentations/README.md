# Presentation Generator

Use this generator for 16:9 cover or title-slide artwork.

## Command

```bash
npm run brand:presentation-cover
```

## Outputs

- `generators/outputs/presentations/arcadeghosts-presentation-cover.svg`
- `generators/outputs/presentations/arcadeghosts-presentation-cover.png`

## What To Upload

- Default deck cover image:
  `arcadeghosts-presentation-cover.png`
- Editable source:
  `arcadeghosts-presentation-cover.svg`
