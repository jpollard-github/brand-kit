# Shirt Generator

Use this generator for shirt front and back artwork.

## Command

```bash
npm run brand:shirts
```

## Outputs

- `generators/outputs/shirts/arcadeghosts-shirt-front.svg`
- `generators/outputs/shirts/arcadeghosts-shirt-back.svg`

## What To Upload

- Front placement:
  `arcadeghosts-shirt-front.svg`
- Back placement:
  `arcadeghosts-shirt-back.svg`

If a shirt vendor is unreliable with SVG, flatten to PNG before upload.
