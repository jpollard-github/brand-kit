# Printify Checklist

Use this as the one-page checklist when ordering your first personal sample run.

## Before You Start

- [ ] create or log into a Printify account
- [ ] choose only three products for the first pass
- [ ] use the files in `for-me/`
- [ ] use the shared logo assets from `shared-assets/`

## First Order

- [ ] one mug
- [ ] one t-shirt
- [ ] one sticker set

## Product Selection

### Mug

- [ ] choose a mug with a simple printable area
- [ ] prefer a dark mug if available
- [ ] confirm the print area is large enough for logo + phrase

### T-Shirt

- [ ] choose a dark shirt blank first
- [ ] confirm front and back print support
- [ ] choose your real size for the sample

### Stickers

- [ ] choose sticker type
- [ ] decide whether to do separate stickers or one small sticker set
- [ ] make sure the designs stay readable at small size

## Files

- [ ] logo asset ready
- [ ] mug graphic ready
- [ ] shirt front graphic ready
- [ ] shirt back graphic ready
- [ ] sticker files ready

## Upload Review

- [ ] upload artwork
- [ ] zoom in on previews
- [ ] check edges and margins
- [ ] make sure no critical text is too close to trim edges
- [ ] make sure dark backgrounds and transparent areas behave as expected

## Final Review

- [ ] choose only one sample of each item
- [ ] re-check shipping before ordering
- [ ] do not over-order on the first pass

## After Arrival

- [ ] judge print sharpness
- [ ] judge material quality
- [ ] decide what feels most “ArcadeGhosts”
- [ ] refine before ordering again
