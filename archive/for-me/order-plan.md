# Printify Order Plan

## First Order

- [ ] 1 mug
- [ ] 1 t-shirt
- [ ] 1 sticker set

## Recommended Sequence

1. choose art direction
2. prepare one design for each product
3. upload to Printify
4. order one sample of each
5. judge quality in person
6. refine before ordering more

## Best Starting Art Direction

Start simple:

- Mug: logo or short phrase plus signal mood
- T-shirt: small front mark plus stronger back graphic
- Stickers: logo + 2-4 small themed designs

Avoid for the first order:

- overly detailed all-over prints
- too much text
- too many colors if they do not add value
