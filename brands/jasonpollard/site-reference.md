# Jason Pollard site reference

Reviewed: 2026-07-16

This is a public-safe, path-free snapshot of the current professional site identity. It contains no private source material.

## Approved colors

- Paper: `#f4f1e9`
- Paper deep: `#e9e4d8`
- Ink: `#112033`
- Muted: `#56616d`
- Teal: `#147d78`
- Teal dark: `#0c5e5b`
- Copper: `#a8532c`
- Line: `#c9c5bb`
- White: `#fffdf8`

## Typography

Body and headings use `Arial, Helvetica, sans-serif`. Labels and the monogram use `ui-monospace, SFMono-Regular, Consolas, monospace`. Headings, navigation, labels, buttons, and the monogram generally use weight 700. Collateral may adjust size and wrapping, but not replace the sans-serif identity with a serif display face.

## Monogram rules

Use a `JP` text mark centered in an ink square with cream lettering. The source icon uses a `64 × 64` view box, `8` unit corner radius, bold monospace at `27`, `1.5` letter spacing, and a visual center at `x=33`, `y=41`. Do not redraw the initials as separate paths, recolor one letter, underline the mark, add glow, or use it as a pattern.

## Approved copy

- “Staff-level software engineer and solutions architect modernizing difficult systems and applying AI with engineering judgment.”
- “I build, repair, modernize, and explain difficult software systems.”
- “Staff / Principal Software Engineer · Solutions Architect”
- “AI accelerates the work. It does not own the decision.”
- BrandKit: “A source-driven TypeScript and Node.js system for producing consistent brand assets from version-controlled configuration.”

Public contact metadata: `jasonpollard.com` and `hello@jasonpollard.com`. Do not invent clients, outcomes, metrics, testimonials, availability, or consulting claims.

## Visual motifs

Warm paper or clean deep-ink fields; an understated 80-unit grid; one-pixel dividers; square panels, tags, and buttons; generous clear space; bold sans-serif hierarchy; monospace technical labels; restrained teal and copper accents. Deep-ink sections are permitted as flat contrast fields.

## Anti-patterns

No serif display typography, pink glow, dramatic radial glow field, sweeping neon-like arcs, glass-panel aesthetic, rounded-card system, decorative logo rings, generic corporate gradients, or generic hero layout that overrules the site’s editorial structure.
