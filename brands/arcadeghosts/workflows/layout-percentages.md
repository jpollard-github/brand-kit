# Exact Text Box Sizes And Placement Percentages

Use this with `layout-spec.md` when building in a print layout tool.

All percentages below assume a standard horizontal business-card canvas.
Treat them as starting points, then nudge visually if needed.

## Coordinate System

- `X` = left edge percentage
- `Y` = top edge percentage
- `W` = width percentage
- `H` = height percentage

## Text Alignment Rules

- all copy left-aligned
- QR centered inside its own box
- keep consistent left edge across title / descriptor blocks

## Typography Ratio

Use approximate size relationships:

- primary heading: `100%`
- secondary line: `45-55%` of heading
- small descriptor / bullets: `32-40%` of heading

In layout terms, if your main front title feels right:

- make the next level roughly half that size
- make the smallest copy clearly smaller but still readable
