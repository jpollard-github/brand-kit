# ArcadeGhosts Theme Variants

This document explains what each named ArcadeGhosts theme is trying to do.

These themes are not separate brands.

They are safe visual modes for the same brand system, mainly through palette shifts and emphasis changes.

## How To Think About Themes

- `default` is the baseline ArcadeGhosts mood
- each theme should feel recognizably related to that baseline
- themes should change emphasis, not identity
- if a theme looks like a different company, it has gone too far

## Current Themes

### `default`

The normal ArcadeGhosts night-signal palette.

Visual idea:

- dark forest-night atmosphere
- warm text
- restrained neon accents
- balanced between mood and legibility

Best for:

- general site/social work
- merch
- most first-pass brand outputs

### `synthwave`

The louder, more neon-forward variation.

Visual idea:

- brighter magenta and violet energy
- more overt retro-futurist glow
- stronger club-poster / arcade-sign color separation
- still readable, but intentionally more showy

Best for:

- social campaigns
- stickers
- promo surfaces
- more playful/event-driven outputs

Avoid when:

- the output is long-form or document-heavy

What `synthwave` means in practice:

- push spectacle more than default
- let magenta, violet, and electric teal carry more of the emotional tone
- keep enough warm text and hierarchy that it still reads like ArcadeGhosts, not a parody poster

### `winter`

The colder, quieter variation.

Visual idea:

- deeper blue-black base
- cooler cyan/ice accents
- softer mood with less heat

Best for:

- wallpapers
- seasonal refreshes
- newsletter headers
- calmer atmospheric surfaces

### `conference`

The event/readability variation.

Visual idea:

- cleaner, brighter contrast
- cooler charcoal/navy base
- stronger teal/cyan signal lines
- less dreamy mood, more clear read at distance

Best for:

- conference badges
- slides
- event signage
- flyers
- banners
- outputs that may be seen quickly or from farther away

What `conference` means in practice:

- prioritize fast recognition over subtle mood
- keep contrast high
- let the typography and hierarchy do more of the work
- reduce some of the hazier “night world” feeling so the asset feels more functional in an event setting

### `minimal-print`

The restrained print-friendly variation.

Visual idea:

- calmer neutrals
- reduced neon intensity
- more controlled warmth

Best for:

- letterhead
- invoices
- proofs
- client-facing documents

### `holiday`

The seasonal warmth variation.

Visual idea:

- warmer amber
- softer festive red-pink energy
- still inside the ArcadeGhosts world, not full holiday-card novelty

Best for:

- year-end updates
- seasonal merch
- gift-oriented social posts

## Future Theme Ideas

Possible next themes worth exploring:

- `late-night-diner`
  Warmer sodium/teal glow with roadside-sign energy.
- `fog-signal`
  More muted and atmospheric, with softer contrast and more misty separation.
- `mono-amber`
  A mostly warm monochrome mode for print, packaging, or understated merch.
- `terminal-night`
  Slightly more utilitarian and systems-oriented, with cooler green-cyan emphasis.
- `sunrise-after-hours`
  A gentler early-morning variant that still feels like the same world after a long night.

If we add more themes, each one should answer:

1. What job is this theme for?
2. What gets emphasized more than default?
3. What should be de-emphasized so the brand still stays coherent?
