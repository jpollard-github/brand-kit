# For Me Merch Pack

This folder is for personal sample merch before any public merch store exists.

Current first-order plan:

- one mug
- one t-shirt
- one sticker set

Platform:

- use `Printify` first

Purpose:

- test what feels good in real life
- learn what actually works with the ArcadeGhosts identity
- avoid overbuilding a public merch system too early

## Suggested Local Structure

- `shared-assets/`
- `mug/`
- `t-shirt/`
- `stickers/`

Keep exported art, mockups, and final order-ready files here.
