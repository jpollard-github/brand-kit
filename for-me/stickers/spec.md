# Sticker Set Spec

## Goal

Create the easiest, most obviously on-brand merch sample.

## Best First Set

Make 3-5 sticker designs:

1. `ArcadeGhosts` logo
2. signal / diner / neon icon
3. arcade-themed mark
4. cat-themed mark
5. short phrase sticker

## Recommended Phrase Options

- `ArcadeGhosts`
- `Strange little experiments`
- `Somewhere In The Pines`
- `Useful tools with a strange little heartbeat`

## Art Direction

- bold silhouette
- strong contrast
- readable at small size
- fewer tiny details than the website itself

## Printify Prep

- [ ] choose sticker product
- [ ] create 3-5 individual files
- [ ] verify each works at small size
- [ ] order one sample set
