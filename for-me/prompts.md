# Merch Image Prompts

Use these as starting points for generating art backgrounds or standalone merch graphics.

## Mug Graphic Prompt

```text
Create a simple, print-friendly graphic inspired by ArcadeGhosts.
Mood: retro neon, cozy diner, strange signal, midnight arcade glow.
Use a dark palette with amber and teal accents.
Composition should work on a mug and remain readable at small size.
No mockup, no mug, no text unless requested separately.
Transparent or isolated composition preferred.
```

## Shirt Back Graphic Prompt

```text
Create a wearable back-print graphic inspired by ArcadeGhosts.
Mood: cinematic, retro arcade, late-night diner, mysterious but inviting.
Should read well from several feet away.
Avoid clutter and avoid highly detailed poster composition.
No mockup, no folded shirt, no people.
```

## Sticker Graphic Prompt

```text
Create a bold sticker-style graphic inspired by ArcadeGhosts.
Mood: strange little experiments, arcade glow, signal lights, night roads.
Strong silhouette, high contrast, readable at small size.
No mockup sheet, no text unless requested separately.
Transparent background preferred.
```
