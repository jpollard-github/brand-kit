# Final Ready-To-Paste Prompts

These are more finalized prompts for making art assets for the first personal merch round.

## 1. Mug Prompt

```text
Create a clean, print-friendly mug graphic for a personal website brand called ArcadeGhosts.

Mood:
- retro neon diner at night
- cozy but a little mysterious
- arcade glow, signal lights, quiet roads, late-night atmosphere

Style:
- minimal enough for a mug
- elegant, not cluttered
- readable at small size
- suitable for a dark mug

Palette:
- deep charcoal / near-black
- warm amber
- restrained teal
- soft off-white highlights

Composition:
- centered or slightly offset standalone graphic
- no mockup
- no mug shape
- no hands or people
- no extra background scene unless it remains simple

Output:
- isolated print graphic
- transparent background preferred
```

## 2. T-Shirt Front Prompt

```text
Create a subtle front-chest graphic for a dark t-shirt inspired by ArcadeGhosts.

Mood:
- understated
- cool
- slightly strange
- wearable in everyday life

Style:
- compact symbol or logo-like composition
- not busy
- no giant illustration
- should work well as a small chest print

Palette:
- off-white with optional amber or teal accent

Output:
- transparent background
- no mockup
- no folded shirt
- no people
```

## 3. T-Shirt Back Prompt

```text
Create a stylish back-print graphic for a dark t-shirt inspired by ArcadeGhosts.

Mood:

- cinematic midnight diner

Style:

Palette:

- no mockup
- no people
- no shirt
```

## 5. Sticker Set Prompt

```text
Create a small set of 4 sticker-style graphics inspired by ArcadeGhosts.

Themes:
1. arcade / quarter / neon machine
2. signal / diner / roadside light
3. cat / tiny chaos / watchful eyes
4. woods / strange signal / night road

Style:
- cohesive set
- bold outlines
- high contrast
- readable at small size

Output:

- transparent background
- no sheet mockup

```
