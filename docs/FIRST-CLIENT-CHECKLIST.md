# First Client Checklist

Reference: 2026-06-28 EDT

This is an operational checklist for using Brand Kit in the real world.

## Bundle Readiness

- [ ] Business cards printed
- [x] Corrected Work With Me business cards ordered
- [x] Email signature installed
- [ ] Capability sheet exported
- [ ] Discovery guide exported

- [ ] Website live

## Notes

- This is a practical readiness checklist, not a generator.
- Brand Kit should now evolve from real consulting work, customer feedback, and proofing instead of speculative new collateral ideas.

## After The Packet Is Clean

1. Wait for the corrected Work With Me business cards to arrive and do a received-print sanity check.
2. Keep using the installed default email signature and do any extra cross-client proofing only if needed.
3. Export and review the capability sheet PDF.
4. Create or update the lead tracker.
5. Add 10-25 prospects.
6. Send 2-3 personalized outreach messages.
7. Track responses.
8. Let real outreach decide future collateral needs.
